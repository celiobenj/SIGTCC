## Como usar

Quando a Julia informar a resposta de uma questão (por exemplo, "Q-05 respondida: ..."), o Claude:

1. registra a resposta, a data e quem respondeu na tabela desta página e muda o status para
   **Respondida**;
2. atualiza todos os documentos de origem listados na questão (spec, Clarifications, plan, tasks,
   data-model, PR) e qualquer código ou teste afetado;
3. se a resposta mudar comportamento, começa pela spec e avisa a Julia antes de alterar código;
4. mostra o que mudou em cada arquivo.

Toda nova pendência que surgir em qualquer spec é registrada no documento de origem **e** aqui, com
o próximo ID livre (a numeração é única para o arquivo inteiro, não por pessoa). Sugestões que não
fazem parte de nenhuma entrega vão para "Sugestões fora do escopo", com ID S-NN.

Status: **Aberta** (aguarda resposta) ou **Respondida**.
